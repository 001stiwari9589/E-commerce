2. LOCAL RUN COMMANDS (TERMINAL)
--------------------------------------------------------------------------------
Open terminal in project root folder (E-commerce):

• Start Local Frontend Dev Server (Vite):
  npm run dev
  --> Opens: http://localhost:5173

• Start Local Express Backend + MongoDB Server:
  npm run server
  --> Opens: http://localhost:5000/api

• Production Build Check:
  npx vite build
